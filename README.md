Designed a multi-layer LLM system for strategic pattern extraction from event-level esports data, 
combining deterministic feature engineering, rule-based semantic compression, and multi-dimensional vector retrieval 
to generate explainable team strategy profiles.

Built a hybrid reasoning architecture using LangChain Documents, vector databases, and tool-based numeric grounding (CrewAI), explicitly separating analytics from semantic retrieval to avoid hallucinations.

Enabled similarity-based retrieval of team-wide strategies across matches and temporal windows, supporting qualitative analysis and comparison without embedding raw event data.
